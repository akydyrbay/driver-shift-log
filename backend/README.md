# Backend: FastAPI + SQLite

## Запуск

Из каталога `backend/`:

```bash
uv sync --locked
uv run --locked python -m app.import_trips data/trips.json   # загрузить пример
uv run --locked uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Документация API — http://127.0.0.1:8000/docs, проверка — `GET /health`.

| Переменная | Назначение |
| --- | --- |
| `TRIPS_DB` | Путь к базе; по умолчанию `backend/data/trips.sqlite3` |
| `WEB_DIR` | Каталог собранного Flutter-клиента (должен содержать `index.html`); если задан, он раздаётся на `/` |

База и каталоги создаются при запуске; повреждённая база останавливает запуск.
CORS разрешён для `http://localhost:8080` и `http://127.0.0.1:8080` — это не авторизация.

## Хранилище

Таблица `trips`: `id` (первичный ключ), `start`, `end` (ISO 8601 с исходным
смещением), `amount`, `commission` (`INTEGER`), `payment`. Версия схемы —
`PRAGMA user_version` (`1`). Запись идёт в транзакции `BEGIN IMMEDIATE`;
при блокировке SQLite ждёт до 5 секунд, затем API отвечает `503`.

## Импорт JSON

```bash
uv run --locked python -m app.import_trips path/to/trips.json [--database path.sqlite3]
```

`--database` имеет приоритет над `TRIPS_DB`. Импорт выполняется одной транзакцией:
идентичные записи пропускаются, конфликт `id` или неверная запись отменяют весь
импорт. Исходный файл не изменяется. JSON — только источник импорта, API работает
с SQLite. Если задана только устаревшая `TRIPS_FILE`, запуск завершится ошибкой.

Готовые файлы: `data/trips.json` — минимальный пример (2 поездки за 2026-10-01),
`data/demo_trips.json` — неделя демо-данных для скриншотов (включает пример).

## API

### `GET /api/trips?date=YYYY-MM-DD` и `GET /api/summary?date=YYYY-MM-DD`

Поездка относится к дню своего **начала** в `Asia/Almaty`, даже если заканчивается
после полуночи. Поездки отсортированы по началу, затем по `id`.

```json
{
  "date": "2026-10-01",
  "trip_count": 2,
  "revenue": 3900,
  "commission": 585,
  "take_home": 3315,
  "cash_revenue": 1500,
  "card_revenue": 2400
}
```

`revenue`, `cash_revenue`, `card_revenue` — до вычета комиссии;
`take_home = revenue − commission`. Пустой день даёт `[]` и нули.
Неверная дата — `422`, ошибка хранилища — `503`.

### `POST /api/trips`

```bash
curl -i http://127.0.0.1:8000/api/trips \
  -H 'Content-Type: application/json' \
  -d '{"id":"t3","start":"2026-10-01T10:00:00+05:00","end":"2026-10-01T10:20:00+05:00","amount":2000,"payment":"cash","commission":300}'
```

Правила: все поля обязательны, неизвестные поля запрещены; время с часовым
смещением и `end > start`; суммы — целые (не строки и не дроби),
`0 < amount`, `0 <= commission <= amount`, максимум int64; `payment` — `cash` или `card`.

| Код | Значение |
| --- | --- |
| `201` | Поездка создана |
| `200` | Такая же поездка с этим `id` уже есть; возвращается исходная запись |
| `409` | `id` занят поездкой с другими данными |
| `422` | Ошибка валидации (`detail` содержит `loc` и `msg`) |
| `503` | Хранилище недоступно; повторите с тем же `id` и данными |

Клиент создаёт `id` один раз и использует его при повторах. Время сравнивается как
момент: `08:10+05:00` и `03:10Z` совпадают. Одновременные повторы создают одну запись.

## Тесты

```bash
uv run --locked python -m unittest discover -s tests -v
```

Покрывают валидацию, хранилище и транзакции, импорт, конкурентную запись,
дневные итоги, границы дня и обработку `POST`. Тесты пишут только во временные каталоги.
