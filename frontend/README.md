# Frontend: Flutter Web

Версия Flutter закреплена в `.flutter-version`. Эмулятор Android не нужен.

## Запуск

Сначала запустите API на `127.0.0.1:8000` (см. [backend/README.md](../backend/README.md)).
Затем из каталога `frontend/`:

```bash
flutter pub get --enforce-lockfile
flutter run -d chrome --web-hostname localhost --web-port 8080 \
  --dart-define=API_BASE_URL=http://127.0.0.1:8000
```

Без Chrome используйте `-d web-server` и откройте выданный адрес в любом браузере.
Порт `8080` важен: backend разрешает CORS только для него.

`API_BASE_URL` — адрес сервера без `/api`, задаётся при сборке. По умолчанию пустой:
запросы идут на `/api/...` того же origin (так работает Docker-образ).

## Возможности

- Календарь, переход на предыдущий/следующий день и «Сегодня».
- Сводка дня и список поездок; состояния загрузки, пустого дня и ошибки с повтором.
- Форма добавления с локальной проверкой; поездка может закончиться на следующий день.
- Время отображается в `Asia/Almaty` независимо от часового пояса браузера.
- Безопасный повтор: при ошибке связи форма сохраняет UUID и данные, повтор не
  создаёт дубль. Черновик не переживает перезагрузку вкладки.
- Суммы — целые, до `9007199254740991` (предел точности JavaScript).

## Проверки и сборка

```bash
flutter analyze
flutter test
flutter build web --release --no-web-resources-cdn --pwa-strategy=none
```

Сборка появляется в `build/web/`. Её можно раздать через backend:
`WEB_DIR=../frontend/build/web uv run --locked uvicorn app.main:app` из `backend/`.
Открытие `index.html` через `file://` не работает.

Тесты покрывают HTTP-клиент, смену дня, запоздалые ответы, ошибки и повторную
отправку, валидацию, поездки через полночь и экран шириной 360 px.
