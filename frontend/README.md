# Flutter Web — дневник смен водителя

Версия Flutter SDK закреплена в `.flutter-version`.

## Локальный запуск

Сначала запустите API по инструкции в `backend/README.md` на `127.0.0.1:8000`.
Затем из каталога `frontend/`:

```bash
flutter pub get --enforce-lockfile
flutter run -d chrome --web-hostname localhost --web-port 8080 \
  --dart-define=API_BASE_URL=http://127.0.0.1:8000
```

Эмулятор Android не нужен. Если Chrome не установлен, запустите web-server и
откройте выданный адрес в Chromium, Brave или другом браузере:

```bash
flutter run -d web-server --web-hostname localhost --web-port 8080 \
  --dart-define=API_BASE_URL=http://127.0.0.1:8000
```

FastAPI разрешает origins `http://localhost:8080` и `http://127.0.0.1:8080`,
методы `GET`/`POST` и заголовок `Content-Type`. Другие origins не разрешены.
`API_BASE_URL` — адрес сервера **без** `/api`; это настройка времени сборки,
после изменения нужен перезапуск/пересборка. По умолчанию URL пустой, запросы
идут к `/api/...` на том же origin, что и интерфейс.

## Возможности

- Выбор даты в календаре, предыдущий/следующий день и кнопка «Сегодня».
- Сводка: «На руки», выручка, комиссия, число поездок, наличные и карта.
- Список поездок; состояния загрузки, пустого дня и ошибки с повтором запроса.
- Форма с локальной проверкой дат, времени, целых сумм и комиссии.
  Ночная поездка может закончиться на следующий день: укажите дату окончания.
- После сохранения обновляются список и сводка дня начала поездки.
  Даты и время считаются в `Asia/Almaty`, независимо от часового пояса браузера.
  На сервер отправляются UTC-времена с `Z`; backend определяет день по Алматы.
- При неизвестном результате сохранения форма сохраняет UUID и исходные данные,
  блокирует редактирование и позволяет безопасно повторить запрос. При явном
  отклонении (`409`/`422`) поля снова доступны. Пока идёт запрос, повторное нажатие
  и закрытие формы заблокированы. Черновик не сохраняется после перезагрузки:
  если закрыли форму после ошибки связи, сначала проверьте список поездок.

Все суммы — целые единицы одной валюты без дробной части. Web-клиент принимает
суммы до `9007199254740991` (точный целочисленный диапазон JavaScript).
Если API возвращает отдельную сумму или итог вне этого диапазона, клиент
показывает ошибку вместо округлённого значения. Лимит SQLite/API остаётся int64.

## Проверки и сборка

```bash
flutter analyze
flutter test
flutter build web --no-web-resources-cdn
```

Сборка находится в `build/web/`. Без `API_BASE_URL` она требует сервер,
обслуживающий API и интерфейс с одного origin. FastAPI раздаёт сборку при заданном
`WEB_DIR`; полный запуск в контейнере описан в [DOCKER.md](../DOCKER.md).
Открытие `index.html` через `file://` не подходит.

Тесты покрывают HTTP-контракт, смену дня, запоздалые ответы, ошибки и повторную
отправку, локальную валидацию, поездки через полночь и экран шириной 360 px.

Для ручной проверки на тестовой базе импортируйте пример и выберите `2026-10-01`:
должны быть 2 поездки, выручка `3900`, комиссия `585`, «на руки» `3315`.
Добавьте поездку, проверьте обновление итогов и сохранение после перезагрузки.
Повторите при ширине окна 360 px. Чтобы не менять рабочие данные, запускайте API
с отдельным путём `TRIPS_DB` и импортируйте пример именно в эту базу.
